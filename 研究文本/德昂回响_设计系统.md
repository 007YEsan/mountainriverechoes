# DesignSystemManifest · 德昂回响

> 德昂族民族音乐播放器 · 设计基线  
> 出品：小花创意 · 2026-10-13

## 一、定位

只播德昂族民族音乐的移动端风格播放器，接山河回响后端真实曲库（e44 德昂族，78 首）。参考网易云音乐播放页 + 底部导航的交互骨架，但视觉语言完全独立。

## 二、配色（深色模式 · 冷暖平衡）

| Token        | 色值        | 含义             |
| ------------ | --------- | -------------- |
| `--bg`       | `#0d1a24` | 深底 · 靛蓝近黑（夜幕）  |
| `--bg-raise` | `#122432` | 抬升面板           |
| `--bg-card`  | `#162b3c` | 卡片             |
| `--line`     | `#22374a` | 分隔线            |
| `--water`    | `#5fb8b0` | 水青 · 主色（水鼓·水波） |
| `--indigo`   | `#4f82b8` | 靛蓝 · 辅色        |
| `--wood`     | `#9a6a46` | 鼓木棕（鼓身）        |
| `--vine`     | `#a34444` | 藤篾红（腰箍·播放键）    |
| `--silver`   | `#e8e6df` | 银白 · 主文字       |

原则：水青/靛蓝为冷色主调（水域），鼓木棕为暖色点缀（器物），藤篾红黑为强调色（播放、选中、收藏），银白为文字。冷暖对半，不偏不倚。

## 三、字体

- 标题/歌词：思源宋体族（Songti SC / STSong / Noto Serif CJK SC），体现民族书卷气
- 正文/UI：系统无衬线（PingFang / Microsoft YaHei），保证可读性

## 四、母题抽象（三元素，均非祭祀符号）

| 母题   | 抽象手法                                          | 应用位置                      |
| ---- | --------------------------------------------- | ------------------------- |
| 水鼓舞  | 同心圆涟漪（`seal` 印章、进度环 `art-ring`、hero `ripple`） | 顶部品牌印章、播放页唱片外环、首页 hero 背景 |
| 藤篾腰箍 | 缠绕的环线/叠带（`bands` 三道弧）                         | 歌词页顶部装饰、导航选中态顶部短线         |
| 茶树   | 叶片剪影 SVG（`leafSvg`，藤篾红）                       | 无封面占位、迷你条默认封面             |

抽象度：中等具象——同心圆/弧线/叶形一眼可辨，但不写实、不出现具体器物或祭祀符号。

## 五、页面与组件

1. **首页**：顶部品牌（同心圆印章）+ hero（播全部）+ 正在聆听列表（前 6）+ 精选曲目列表
2. **播放页**：旋转唱片（有封面）+ 进度条 + 五键控制（模式/上一首/播放/下一首/收藏）
3. **歌词页**：三道藤篾弧装饰 + 居中歌词滚动（当前行高亮）
4. **底部导航**：首页 / 歌词 / 播放（三页）
5. **迷你播放条**：列表页底部悬浮，点开回播放页
6. **设置抽屉**：柔和动效开关（减少旋转/过渡）

## 六、交互与可达性

- 播放键 76px，控制键 52px，导航项 ≥44px，全部满足触控标准
- 动效柔和：转场 0.32s、进度平滑、唱片旋转 22s；`reduced` 模式可关闭全部动画
- 语义化：`aria-label`/`role="slider"`/`role="switch"`，歌词当前行视觉 + 语义同步
- 深色固定，对比度满足 WCAG AA

## 七、技术落地

- 单文件 `webui/templates/deang-player.html`（内联 CSS/JS，无 CDN 依赖）
- 路由 `/deang`，复用后端接口：`/api/playlist`（曲库）、`/api/preview`（播放直链，支持 Range）、`/api/cover`（封面代理）、`/api/lyric`（歌词）
- 封面走 `/api/cover?url=` 代理（B 站 archive 图需代理）
